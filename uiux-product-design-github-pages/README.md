# Lộ trình UI/UX Product Design · 15 tháng

Website tĩnh bằng HTML, CSS và JavaScript thuần, được biên soạn từ tài liệu lộ trình nguồn. Nội dung gồm 15 tháng, 180 buổi học, các quy trình, tiêu chí đầu ra và phụ lục.

## Chạy trên máy

Mở index.html bằng trình duyệt. Không cần cài thư viện hay chạy máy chủ.

## Đưa lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Tải các tệp trong thư mục này lên thư mục gốc của repository: index.html, app.js, roadmap-data.js, styles.css và favicon.svg.
3. Mở Settings → Pages.
4. Trong Build and deployment, chọn Deploy from a branch.
5. Chọn nhánh main và thư mục /(root), sau đó lưu.
6. Mở đường dẫn Pages mà GitHub hiển thị sau khi triển khai.

## Tính năng

- Tìm kiếm tiếng Việt không phân biệt dấu.
- Mở hoặc thu gọn từng tháng hay toàn bộ lộ trình.
- Đánh dấu buổi đã học và theo dõi tiến độ.
- Tiến độ được lưu trong trình duyệt của thiết bị hiện tại.
- Bố cục tự điều chỉnh trên điện thoại, máy tính bảng và máy tính.
- Giao diện nền trắng, chữ đen dịu và các sắc độ xám; hỗ trợ in hoặc lưu thành PDF.
